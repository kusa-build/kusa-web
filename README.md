# Kusa

Astro landing page for Kusa, a software company named after the Filipino word for doing something naturally or automatically.

## Commands

```sh
npm install
npm run dev
npm run check
npm run build
```

The full-screen terminal projects `KUSA` as interactive three-dimensional ASCII art. Every five seconds it glitches into a rotating loading form and resolves to `AUTOMATIC`. Move the pointer to rotate the artwork, or press anywhere to cycle color palettes.
